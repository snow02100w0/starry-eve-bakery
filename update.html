✦ WEBSITE UPDATE GENERATOR ✦

1 貼上你匯出的 JSON

從星夕烘焙屋網站的「管理員面板 → 匯出 JSON」下載檔案，把整份內容貼到下面（也可以直接選檔）：

2 產生新的 index.html

按下按鈕會產生更新後的 index.html 並自動下載。

3 上傳到 GitHub

  1. 打開你的 GitHub Repo：github.com/snow02100w0/snow
  2. 點原本的 index.html → 右上角鉛筆圖示旁的 ... → Delete file（或直接進去後點 Edit 貼上取代）
  3. 回到 Repo 首頁 → Add file → Upload files → 把剛下載的 index.html 拖進去
  4. 下方按 Commit changes
  5. 等 1 分鐘 → 打開 snow02100w0.github.io/snow/ → Ctrl+F5 硬重新整理

⚠️ 提醒：客人瀏覽器裡如果之前存過舊資料，需要清 localStorage 或用無痕視窗才會看到新內容。你自己也是一樣，建議測試時用無痕視窗。
